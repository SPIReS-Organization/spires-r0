# spires-r0

Background (R_0) reflectance production for the
[SPIReS](https://github.com/SPIReS-Organization) package family: builds the
snow-free background reflectance the inversion uses as a reference.

Produces background spectra conforming to the I/O→inversion boundary defined in
[`spires-contract`](https://github.com/SPIReS-Organization/spires-contract).

> **Status:** scaffolding only. The package layout and dependency on
> `spires-contract` are in place; the implementation is to be filled in. See
> `examples/` for the workflow this package will cover.
